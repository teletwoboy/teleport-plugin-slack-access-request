# HOW TO CONTRIBUTE

There are several ways you can contribute to `teleport-plugin-slack-access-request` :) <br>
When submitting a PR, please check the available labels and include an appropriate title accordingly <br>
Please follow the commit message format below: 
```
category: title 

1. Hi
2. Love
3. ...
```

<br>

## Process

This section describes how to contribute to this repository.

### Contributing via Pull Request

#### 1. Fork this repository

#### 2. Clone forked repository

```
# in your workspace
$ git clone https://github.com/steamedEggMaster/terraform-google-multi-env.git
$ cd terraform-google-multi-env
```

#### 3. Write Your Code

#### 4. Apply Lint

```
$ go mod tidy
$ go mod verify
$ golangci-lint run -v
```

#### 5. Commit your code

```bash
$ git add .
$ git commit -m "[your description]"
$ git push origin main
```

#### 6. Create a pull request for your commit

### 📌 Pull Request Template
```md
## #️⃣ Issue Number

<!--- Related issue(s), e.g., #12, #45 -->
<!--- Please make sure to link the issue for traceability -->

## 📝 Summary

<!--- Briefly explain the purpose of this PR. Focus on *what* was changed and *why*, rather than *how*. -->

## 📁 Category (from issue)

<!--- Select the category that matches this PR (should match issue category) -->

- [ ] `feat` – New feature
- [ ] `fix` – Bug fix
- [ ] `chore` – Build, config, or dev-related task
- [ ] `docs` – Documentation
- [ ] `style` – Code style/formatting (no logic change)
- [ ] `refactor` – Code refactoring
- [ ] `test` – Add or update tests
- [ ] `perf` – Performance improvement
- [ ] `rename` – Rename files/variables/etc.
- [ ] `remove` – Code/File/Folder removal
```

<br>

### Contributing via Issues

If you are not familiar with the pull request workflow, you can also contribute by creating an issue.

---

## Categories for Issue

- feat (new feature)
- fix (bug fix)
- chore (build/config/update)
- docs (documentation changes)
- style (formatting/style changes)
- refactor (code refactoring)
- test (add or update tests)
- perf (performance improvements)
- rename (renaming files or variables)
- remove (code/file/folder removal)
